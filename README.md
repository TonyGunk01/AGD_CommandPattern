# CommandTactics-CommandPattern

Command Tactics is a turn based game developed in Unity 2D and programmed in C#. 2 players controls a team of characters each.

Here I have used the concept of Command Patterns. Just like encapsulation wraps code and data into a single unit, command patterns entire method invocations, i.e., it allows to simplify specific tasks or actions as individual commands. Using this way, the service requesting the action doesn't have to concern itself with how the task is executed, it simply uses the predefined command to accomplish it.
